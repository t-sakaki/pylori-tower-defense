## 1. ゲーム概要・世界観設計

### 🌍 世界観：「胃袋要塞 ミクロ・ガーディアンズ」

舞台は、人間の胃の中。しかし、ここは生きた組織として描かれる。

**胃粘膜**は「生体防壁都市（ガストロポリス）」であり、無数の上皮細胞たちが平和に暮らしている。彼らの上には「胃酸の海」が広がり、これが天然の防衛壕となっている。

ある日、空から「スパイラル・インベーダー」——**ピロリ菌（Helicobacter pylori）**が降ってくる。彼らはウレアーゼという特殊兵器で胃酸を中和し、粘膜に穴を開けて細胞毒素（CagA/VacA）をばらまき、炎症・潰瘍・そして最悪の場合「がん化」へと導こうとする。

プレイヤーは「**胃袋要塞の司令官（ガストロ・コマンダー）**」となり、医療チームと免疫細胞たちを指揮して、7日間の激闘を乗り越え、胃を救う。

#### 🎭 演出アイデア
- **オープニング**：胃カメラ視点のCG。ピロリ菌が螺旋状に泳いで胃壁に着地する。
- **日次演出**：毎朝「朝の服薬タイム」として、カットシーンで司令室のモニターに「DAY 1 → DAY 2」と表示。胃酸の海の色やBGMが日に日に変化（初期は荒れ狂う赤 → 除菌成功で穏やかなピンクへ）。
- **エンディング分岐**：
  - 成功：「除菌完了！胃は平和を取り戻した」→ 実際の医療知識クイズで復習
  - 失敗：「ピロリ菌が定着…慢性胃炎へ」→ リトライを促す教育的メッセージ

### 👾 敵キャラクター（ピロリ菌軍団）デザイン案

| 敵名 | 外見 | 能力 | 弱点 |
|------|------|------|------|
| **ピロリ・スカウト** | 小さな螺旋バクテリア。素早く泳ぐ。 | 基本攻撃。ウレアーゼで胃酸を薄める。 | 胃酸ダメージ |
| **ウレアーゼ・タンク** | 巨大なピロリ菌。背中にウレアーゼの泡を溜めるタンク。 | 範囲内の胃酸を一気に中和（pH上昇ゾーンを展開）。 | プロトンポンプ（胃酸強化） |
| **CagA・スナイパー** | 鋭い針を持つ変異種。 | 遠距離から上皮細胞に「CagA毒素」を射撃。細胞が異常化（がん化予備軍）する。 | 抗生物質の集中攻撃 |
| **VacA・ボマー** | 膨らんだ体躯。破裂する。 | 死亡時にVacA毒素を放出。周囲の細胞に「穴あきダメージ」（潰瘍化）。 | 遠距離で先制攻撃 |
| **バイオフィルム・コア** | 複数のピロリ菌が集団で粘液の塊を形成。 | 極めて高い防御力。中から次々とスカウトを生産。 | 乳酸菌の「バイオフィルム分解」 |
| **BOSS：ピロリ・オーバーロード** | 7日目に出現。全能力を持つ巨大変異体。 | 全スキルを使用。胃酸を完全に無力化し、がん化エリアを広げる。 | 7日間の服薬コンボで弱点が露出 |

### 🛡️ プレイヤーユニット＆スキル

#### 防衛タワー（配置型）
| ユニット名 | 役割 | 詳細 |
|-----------|------|------|
| **胃酸キャノン（プロトンポンプ）** | 基本攻撃塔 | 胃酸の塊を発射。ウレアーゼ未使用の敵には大ダメージ。ウレアーゼで中和されるとダメージ激減。 |
| **アモキシシリン・ガンナー** | 対菌攻撃塔 | ペニシリン系抗生物質を発射。ピロリ菌に継続ダメージ。バイオフィルムには通りにくい。 |
| **クラリスロマイシン・レーザー** | マクロライド攻撃塔 | 貫通ビーム。複数の敵を貫通。CagA菌に特効。 |
| **メトロニダゾール・トラップ** | 設置型爆弾 | ニトロイミダゾール系。敵が通過時に爆発。VacAボマーの先制破壊に有効。 |
| **粘膜バリア・シールド** | 防衛壁 | 上皮細胞を守るバリアを展開。CagA/VacAの直撃を防ぐ。耐久値あり。 |
| **乳酸菌・サポートドローン** | 補助ユニット | 周囲のタワー回復＆バイオフィルムを溶解。胃酸環境を整える。 |

#### アクティブスキル（プレイヤー手動発動）
| スキル名 | 効果 | クールダウン |
|---------|------|-------------|
| **高用量プロトンポンプ阻害（PPI）** | 全画面の胃酸濃度を一時的にMAXに。ウレアーゼを無力化。 | 長め |
| **除菌ショック療法** | 3剤（PPI＋アモキシシリン＋クラリスロマイシン）を同時投与。画面内の敵に大ダメージ。 | 1日1回 |
| **免疫細胞突撃（マクロファージ）** | マクロファージ部隊を召喚。自動で敵を追撃。 | 中程度 |
| **緊急修復（粘膜再生）** | 損傷した上皮細胞を回復。潰瘍エリアを元に戻す。 | 短め |

### 📅 「7日間服薬」をゲームシステムに落とし込むアイデア

#### コアシステム：「リアルタイム×ゲーム内時間」のハイブリッド

| 要素 | 設計 |
|------|------|
| **7DAYウェーブ** | ゲームは7つの「DAY」に分かれる。各DAYは5～10ウェーブ。 |
| **朝・昼・夕・寝前の服薬タイミング** | 各DAY内で「服薬タイム」が発生。タイミング良くスキルを使うと「コンプライアンスボーナス」が発動（攻撃力アップ、回復など）。 |
| **服薬ミスペナルティ** | ゲーム内で「薬を飲み忘れた」状態になると、ピロリ菌が耐性を獲得（敵が強化）。最悪、除菌失敗エンド。 |
| **リアル連動モード（拡張）** | 実際に毎日プレイヤーがアプリを開いて「服薬報告」をすると、ゲーム内でボーナスアイテムがもらえる。 |

#### 日次進行のドラマチック演出
- **DAY 1-2**：「侵攻開始」——ピロリ菌が散開。基本種が主体。
- **DAY 3-4**：「バイオフィルム形成」——集団で防御力が上がる。乳酸菌が鍵。
- **DAY 5-6**：「変異・毒素増強」——CagA/VacA型が大量出現。緊張感MAX。
- **DAY 7**：「最終決戦」——ボス「ピロリ・オーバーロード」登場。7日間の服薬コンボがないと壊滅的。

## 🎯 まとめ：このゲームの「面白さの核」

1. **医学的正確性 × ゲーム性**：胃酸中和、3剤併用療法、CagA/VacAの作用を**ギミックとして自然に体験**できる。
2. **7日間のドラマ**：毎日が「最終決戦への布石」。服薬を忘れるとゲーム内でも penalty が出る「自己管理の緊張感」。
3. **視覚的インパクト**：ミクロな世界を「要塞都市」として描くことで、医療知識に馴染みのないユーザーでも感情移入できる。
4. **拡張性**：ハッカソンでは「DAY 1だけのデモ」として完結させつつ、7日分のデータをローカルに保存しておけば、後から全7DAYを解放できる設計。
